VAULT RUSH KEYPAD CLICK FIX v1.2.1

Open src/index.css in your project and paste the entire contents of
src/keypad-click-fix.css at the very end of the file.

Then run:
  npm run build
  npm run dev

This patch prevents the transformed laptop base, keyboard, trackpad, mascot,
and hazard decorations from intercepting clicks or taps intended for the
SecurityGrid buttons.
