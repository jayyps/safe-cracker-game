# Vault Rush v1.6.0 — Hacker Terminal Theme

This release removes the cartoon arcade presentation and replaces it with a darker hacker-console visual system.

## Visual changes

- Matrix-style code rain
- Root terminal prompts and system logs
- Green/cyan encrypted-console palette
- Silent red breach warnings on Level 3
- Glitch title treatment
- Black-glass laptop shell
- Terminal scanlines and command readouts
- No comic bursts, mascot, speech bubbles, or cartoon sirens

## Gameplay

Gameplay is unchanged from v1.4/v1.5:

- Levels 1 and 2 use memory sequences
- Level 3 uses Emergency Shutdown reaction targets
- Difficulty controls starting time only
